MATCH-3 GAMEPLAY

Every move can change the board.

Complete objectives within the available moves, combine food tiles and create powerful special pieces.

3

Match Three

Connect matching food tiles to clear them from the board.

4

Line Clears

Four-tile matches create powerful row or column clearing pieces.

💣

Bombs

T and L matches create explosive special tiles.

🌈

Color Bomb

Five-tile matches create one of the most powerful pieces in the game.
